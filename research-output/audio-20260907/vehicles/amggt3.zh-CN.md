# MERCEDES AMG GT3 声音档案

目标：2019发布、2020 Evo规范GT3赛车；赛事/BoP仍需留档。
核对状态：`MODEL_VERIFIED_EVENT_UNRESOLVED`；全部听感：`LISTENING_NOT_RUN`。

动力：6.3L名义排量，实际6208cc自然吸气V8（M159家族）；6速序列式赛车变速箱，后置transaxle。增压需求：`NOT_APPLICABLE`。

研究V8排气脉动、快速切火换挡、车内传动啸叫和赛用底盘冲击。录音中的齿轮声可能掩盖排气；不能用单一低频V8层承担全部赛车声音。

## 驾驶状态与录音位置

| 项目 | 研究/取材重点 |
| --- | --- |
| 启动/怠速 | 启动、暖机、pit limiter受限行驶；限速器状态不能用常规怠速代替。 |
| 负载/转速 | 赛事范围内的稳定负载与快速加速，BoP及消音配置必须与录音一起记录。 |
| 收油/传动 | 序列式升挡切火、降挡补油、传动加/减载啸叫；禁止套道路双离合或8AT。 |
| 进气/增压 | 自然吸气进气，无turbo；AMG GT/GT R/GT4的4.0涡轮不是目标发动机。 |
| 录音位置 | 发动机、排气口旁、车内安全隔热位置及后部传动机位；路旁通过/回响另轨。 |
