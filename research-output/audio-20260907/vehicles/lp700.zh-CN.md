# LAMBORGHINI LP700 声音档案

目标：2011 Aventador LP700-4 Coupé。
核对状态：`TARGET_SPEC_VERIFIED`；全部听感：`LISTENING_NOT_RUN`。

动力：L539家族6.5L、60度自然吸气V12、700CV；7速ISR自动化单离合手动变速箱。增压需求：`NOT_APPLICABLE`。

研究低转V12脉动向高转密集谐波的变化、后部进气及机械声；ISR换挡过程应区别于PDK。2014同款录音是最接近的采购线索，未宣称与2011完全相同。

## 驾驶状态与录音位置

| 项目 | 研究/取材重点 |
| --- | --- |
| 启动/怠速 | 点火建立、暖怠速和熄火独立，驻车补油只作瞬态。 |
| 负载/转速 | 发动机/排气/座舱同步steady与ramp；轻重负载分别取材。 |
| 收油/传动 | 慢/快驾驶下ISR换挡断扭与恢复、收油；高转限转仅短时参考。 |
| 进气/增压 | 后部自然吸气；不得加入turbo/supercharger。排气阀和改装状态需向录音商确认。 |
| 录音位置 | 中后置机舱左右、尾管侧向、车内耳位、车外ORTF/XY通过。 |
