# BMW M5 G90 声音档案

目标：2024 G90轿车、欧规M HYBRID；不包括G99旅行版。
核对状态：`TARGET_SPEC_VERIFIED`；全部听感：`LISTENING_NOT_RUN`。

动力：S68家族4.4L双涡轮V8 + 电驱动；8速M Steptronic，电机集成于变速箱。增压需求：`REQUIRED_TURBO_AND_HYBRID_DISTINCT`。

必须区分排气阀开度、涡轮进气/机械、电机与车内IconicSounds。座舱视频不是未经声效加工的V8干声；纯电驶离不应继续播放怠速。

## 驾驶状态与录音位置

| 项目 | 研究/取材重点 |
| --- | --- |
| 启动/怠速 | 冷/热ICE启动、停止再启动、纯电READY分别标记，不能将READY当发动机已启动。 |
| 负载/转速 | V8轻/重负载与阀门模式，电机辅助出现的状态；分离车外真实动力声和座舱设计声。 |
| 收油/传动 | 8AT升降挡、滑行及再加速；不能套F10双离合声音或夸张赛用回火。 |
| 进气/增压 | 涡轮升压、卸载声只在真实可闻证据支持下采用；普通大泄压BOV不作为准确S68。BMW电驱提示/boost track另属设计音，不自动获得复用权。 |
| 录音位置 | 前机舱/空气入口、两侧后尾管、车内（注明IconicSounds开关）、外部纯电低速；风噪/胎声独立。 |

## 不可混用

- F10/F90 M5库当G90
- G99混剪当纯G90
- 改装OPF-delete/Akrapovic当欧规原厂
- 自然吸气V8代理
- 科幻UI声当真实电机/AVAS
