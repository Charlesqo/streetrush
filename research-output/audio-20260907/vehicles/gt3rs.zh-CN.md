# PORSCHE GT3 RS 声音档案

目标：992代911 GT3 RS，项目欧规525PS（2022发布）。
核对状态：`TARGET_SPEC_VERIFIED`；全部听感：`LISTENING_NOT_RUN`。

动力：4.0L自然吸气水平对置六缸，9000rpm上限；7速PDK双离合。增压需求：`NOT_APPLICABLE`。

高转密集六缸纹理、后部进气和排气都需保留；PDK换挡短暂断扭与补油降挡是重点。官方整圈可校对状态关系，不能从车内混音推导干净排气轨。

## 驾驶状态与录音位置

| 项目 | 研究/取材重点 |
| --- | --- |
| 启动/怠速 | 启动、稳定怠速、熄火及风扇应有分离依据。 |
| 负载/转速 | 后空气入口、机械接触/机舱、尾管；低中高转轻重负载，接近9000rpm的短扫转。 |
| 收油/传动 | PDK升挡/降挡/收油；普通GT3手动声不能充作RS变速箱。 |
| 进气/增压 | 独立节气门进气，NOT_APPLICABLE涡轮；库标签Blowoff不证明此车有增压。 |
| 录音位置 | 后翼下方空气入口附近、后发动机、后尾管、车内、路旁；不借用GT4 RS座舱进气布置。 |
