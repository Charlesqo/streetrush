# BMW M3 E30 声音档案

目标：E30 M3基础2.3L、200PS、5速手动。
核对状态：`TARGET_SPEC_VERIFIED`；全部听感：`LISTENING_NOT_RUN`。

动力：S14B23 2302cc自然吸气直列四缸；5速手动。增压需求：`NOT_APPLICABLE`。

应研究高转直四与独立节气门进气、机械纹理和排气共鸣；道路空气箱和催化配置会影响音色，DTM尖锐进气声不能直接复制。此为结构推断。

## 驾驶状态与录音位置

| 项目 | 研究/取材重点 |
| --- | --- |
| 启动/怠速 | 暖怠速稳定片段与启动过程分开，避免故障链条声。 |
| 负载/转速 | 同转速不同负载；空气箱和排气分轨，对比中转到高转的纹理变化。 |
| 收油/传动 | 手动换挡有动力中断；记录补油降挡、收油和空挡转速回落，常态不能夸张持续放炮。 |
| 进气/增压 | 进气具有研究价值，但无涡轮；DTM碳空气箱、2.5L赛车凸轮属不同目标。 |
| 录音位置 | 前机舱/空气箱、后尾管、车内封闭驾驶位；外部通过单独保持空间信息。 |
