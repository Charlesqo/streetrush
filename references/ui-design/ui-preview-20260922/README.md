# StreetRush 独立 UI 预览

打开 `index.html` 即可查看，无需安装依赖。也可在本目录运行 `node server.cjs`，访问 http://127.0.0.1:5188 。

包含选车、驾驶 HUD、暂停和结算。六车选择、AT/MT、画面切换、暂停/继续与键盘左右键可交互。顶部标签与底部“下一画面”属于预览工具。

这是独立视觉原型，没有接入游戏运行链、物理、计时或存档。场景为项目现有渲染截图。驾驶页固定使用 MX-5 截图，无论选车页选择了哪辆车；顶部和底部均标明静态示例。界面的速度、圈速、纪录为设计演示数据，不是实测成绩。“开始计时赛”和“再跑一次”仅切换预览画面。

风格采用同一套字级、朱红主强调色、暖白文字和斜向细节。青色只用于圈速改善。场景本身提供主要色彩。字体使用本机 Bahnschrift 与微软雅黑，不需远程字体。

车辆数值摘自项目 `src/config.js`，只用于界面排版演示；不表示现实车辆规格认证。素材出处见 ASSETS.md。
