## 流程与边界

1. CC0 实拍 PBR 材质原样保存，记录作者、许可、尺度、通道与校验值。
2. Blender 参数化建模脚本与可编辑 .blend，组织完整资产集合及根节点。
3. 单进程首轮渲染；实际检查建筑比例、边缘过粗、材质塑料感、重复感、地表过渡、设施构造和穿插。
4. 根据可见问题修改；保留首轮证据。
5. 最终 6–8 个视角：整体、驾驶视点、反向、维修楼、设施、地表、资产分组展示；GLB 导出并验证贴图和尺度。
6. .blend / GLB / 完整材质 / 组合场景 / 多角度预览 / 源码 / 资源来源 / 参照差距报告一起交付。

验收以模型和材质的实际画面为准。不能凭模型存在或导出成功称成熟游戏同等质量。游戏接线、碰撞、目标设备帧率与生产运行验收 NOT_RUN。

设备约束：M4 16GB，单个 Blender 4.5.13 LTS 建模或渲染进程、3 个 CPU 线程，常规 2K 贴图，草稿先小图。重复执行批次使用 gpt-5.6-luna / max 子代理，批次完成结束，不保留空转进程。
