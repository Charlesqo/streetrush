# 沿曲线生成路肩

本组件使用 Blender 原生 Geometry Nodes。打开编辑文件后，改曲线或参数即可更新几何，不需要安装插件或每次运行 Python。当前制作验证完成后，实图和检查记录会写入 `previews/kerb_*`、`review/kerb-generator-checks.json`。

## 如何编辑

1. 打开 `scene/longwan_kerb_procedural.blend`。
2. 选择名字包含 **EDIT PATH** 的曲线，按 Tab 进入编辑模式。`02 Corner` 和 `03 S Curve` 是可直接移动控制点的贝塞尔曲线。
3. 移动控制点，路肩会沿曲线重新生成；控制点也可以改变高度。
4. 选择对应的路肩网格对象，在 **Path · Width · Ribs · Wear** 几何节点修改器里调参数。

| 参数 | 用途 |
|---|---|
| Path | 指定作为内侧边线的曲线 |
| Width m | 路肩宽度，默认 1 m |
| Use full path | 开启时使用整条路径；关闭后由 Length m 截取 |
| Length m | 路肩长度，以米为单位，上限为路径实际长度 |
| Slope enabled | 横向斜面的开关，与齿纹独立 |
| Cross slope deg | 横向坡度，默认 4°；0° 为水平基面 |
| Ribs enabled | 纵向齿纹的开关 |
| Rib rise m | 外侧边缘的真实齿状起伏增量，默认 0.025 m |
| Rib pitch m | 沿曲线相邻齿的间距，默认 0.5 m |
| Wear seed | 改变现有表面贴图的取样位置，打散重复 |
| Surface | 红白涂层 PBR 材质 |
| Concrete body | 未涂装侧面和底部的混凝土材质 |

`Rib rise m` 不是总离地高度。内侧唇口在路径上方约 3 mm，横向斜面逐渐抬升外侧，在此基础上增加齿状起伏。默认 1 m 宽、4° 横坡、25 mm 齿高时，外侧峰值离路径高度约 98 mm。底面在路径下方 80 mm，随路径高度变化。红白条带按曲线实际距离分布，默认每 1 m 换色。

长度 × 宽度是便于布置的名义覆盖面积，例如 12 m × 1 m = 12 m²；它不等于带坡度、齿纹和弯曲后的精确表面积。生成方向位于路径前进方向的左侧。急弯需要检查内侧是否重叠，目前不自动解决自相交或铺到任意地形。

## 如何避免所有位置都一样

结构尺寸由用途确定；不同区段可以有不同宽度和起伏，磨损种子改变纹理采样。它不会凭空产生新的扫描内容，完整区域还需要局部轮胎痕、积灰、修补等来形成使用差异。

一套组件用于多个区段时，保留独立路径和参数即可。直线、弯道与 S 弯示例用于展示这种复用方式，不是新增整条赛道。

## 后续如何应用

保留 `.blend` 中的曲线与节点作为编辑源，导出时将实际生成的网格与 PBR 材质保存为 GLB。再按赛道对应区域摆放生成模型。当前不要求游戏运行时携带 Blender 节点，也不把一条固定直线硬放到所有位置。

本轮不接入游戏。曲线生成和几何形状的验证不等于碰撞、车辆响应或游戏帧率验收。
