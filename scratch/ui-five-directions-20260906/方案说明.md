# StreetRush：五套玩家界面方案

交付为设计预览，包含五套主菜单、选车与驾驶 HUD，共 15 屏；没有接入生产游戏界面。所有游戏界面内的文案仅用于选择、发车、驾驶状态、计时、目标和操作提示。

五套采用本项目实际渲染的龙湾赛道与六辆现有车辆。主菜单和选车使用同一组车辆截图，驾驶使用同一组对应车辆的追车截图；摄影机取景和 UI 遮罩可以随布局调整。车辆不是生成图片。对照默认选择 MX-5，以排除不同车辆和背景对判断的影响。

## 统一功能和数据

- 主菜单：开始比赛、选择车辆、驾驶设置、声音开关，龙湾国际赛道、午后干地、三圈计时挑战、当前车辆、操作提示。
- 选车：六辆车、前后切换与直接选择、车辆名称、驱动形式、极速展示值、加速和操控分数、金银铜三圈目标、最佳单圈、三圈最佳、确认发车。
- HUD：圈数、总用时、本圈用时与有效性、分段和差值、最佳单圈、检查点进度、下一奖牌目标与预计差值、车速、挡位、AT/MT、转速、油门、刹车、路面、接地与辅助状态、暂停与驾驶设置。
- 圈速、纪录、118 km/h、5420 RPM 等是共用的界面示例值，不是车辆测试结果。车辆配置展示与奖牌门槛分别参考 `src/config.js` 和 `src/race-goals.js`；加速、操控明确标为 /100 分数。
- 可操作的预览流程：选方案、选页面、查看总览、放大单屏、切换六辆车、发车进入对应车辆 HUD、暂停/继续、返回菜单、设置声音和 AT/MT。预览不会启动实际比赛或播放游戏声音。

## 可读性与后续取舍

计时和仪表使用稳定底板或局部遮罩，保证亮天空与暗路面上的读数对比。正前方道路和车辆周边留出主要视野；差值带正负号，圈数和检查点同时显示数字，避免仅用颜色表达状态。驾驶画面不使用持续闪动、循环装饰动画或长段文字。

主体构图按 16:9 桌面游戏设计。对照缩略图用于比较结构，可放大查看；单屏预览对较窄浏览宽度进行了重新排版。触摸驾驶的完整按钮布局不在本轮三个核心页面的交付范围内。

建议先比较 01 与 05：01 更贴近当前计时玩法的阅读习惯；05 更突出车与路面的画面。02、03、04 分别适合作为街头、经典车与街机方向的明确视觉选择。

## 文件与验证

- `review.html`：可独立打开的本地对照预览。
- `previews/all-five-directions.png`：五行三列对照图；各方案的主菜单、选车、HUD 也分别导出 PNG。
- `preview-source.html`：可编辑的界面源稿；`build-preview.mjs` 将实景数据嵌入。
- `scenes/`：真实游戏截图与来源记录。
- `verification.json`：浏览器布局及交互检查记录。此检查只针对设计预览，不代表游戏生产测试或物理验收状态。
