# 游戏内维修区局部试装

入口：http://127.0.0.1:5173/?pitpreview （Vite 开发模式）

使用当前游戏场景、天空、光照和渲染管线；加入维修楼、赛控塔、岗亭及维修设施。在起跑直道旁按米制布置，新增铺装作业区。面板提供驾驶高度、维修区近景、直道全景，以及同机位原场景/试装切换。

本次新增代码：`src/dev-pit-preview.js`；`src/main.js` 仅增加显式开发参数入口。原有代码及独立美术源文件保留。此版本是视觉局部试装，没有新增碰撞体，不是整条赛道接入或性能验收。

`extract.py` 从原 296 MB 组合 GLB 提取 22 组设施和路边组件，保留所选几何及材质连接，贴图试装副本最大边为 1024；输出约 94.7 MB；复用一段 24 m 路边模块，唯一网格约 93.2 万三角形（四次摆放的实际渲染量更高）。仍需后续针对实际目标设备做优化，不能据此宣称已满足性能要求。

## 路肩验证

`check_kerb.py` 实际打开 `longwan_kerb_procedural.blend`，临时更改宽度、关闭齿纹、移动曲线路径点。结果见 `kerb-actual-check.json`，原文件未保存修改。

- 宽度：1 m → 0.65 m，网格边界跟随变化。
- 关齿纹：最大高度约 0.07324 m → 0.04831 m。
- 修改路径：边界和顶点数发生变化，证明保存文件中的节点确实更新网格。
- 该能力在 Blender 编辑源中；GLB 导出结果为固定网格。
- 不会自动贴合任意地形或修复急弯自相交。应用现有赛道还需导出对应边线路径、控制分段密度。

游戏碰撞/车辆响应及目标设备性能：NOT_RUN。本次只核查路肩几何编辑能力。

加入一侧的四段实体路肩、钢护栏、围网，以及看台、门架、维修区隔离墙和原有铺装材质。仅在试装开启时隐藏对应范围的旧视觉实例；关闭后恢复保存的原实例矩阵。所有原始模型保持原样。

玻璃移除污渍法线和粗糙度贴图，使用零粗糙度、零厚度的清玻璃透射材质。透明混合方案因反射过弱未保留。试装页面同步旋转 HDR 天空与太阳以照亮建筑正面，固定最高 1.5 倍像素比检查细线。四种机位包含玻璃近景。同机位开关比较使用相同的当前试装光照。

这是视觉试装：新设施未增加碰撞，目标帧率尚未验收。细围网的远景抗锯齿和资产体积仍需继续优化。

## 2026-09-08：第一段主直道修整（当前状态）

当前约 96 m 试装段采用连续白线与平齐沥青边带，不设置连续红白路肩。原试装四段路边模块的红白涂层和对应凸起混凝土几何已从派生 GLB 中移除，排水和围栏基础保留。游戏原有路肩、断续边线只在该段的视觉预览中隐藏，同机位比较会恢复原矩阵。隔离墙下移 0.1 m，使墙脚落地。

优化：重复路边组件共享网格，并按相同网格/材质合为 InstancedMesh；GLB 内完全相同的二进制数据去重。包体 94,720,384 → 86,258,008 字节（减少 8.93%）。唯一网格 931,717 → 895,699 三角形。保留纹理分辨率，未以降低整幅画质换取本轮包体缩减。网格索引和缓冲范围检查通过，详见 `block-01-validation.json`。

视觉定位：先完成当前主直道与维修区样段，再逐段处理相邻区域。未来路肩按每个弯的内侧、出口外侧和连接位置明确布置，并非沿全赛道统一铺设。尚未把这套视觉布局推广到全赛道，也未修改表面判定或碰撞。新旧视觉位置与物理的一致性仍是正式接入前的必做项。
