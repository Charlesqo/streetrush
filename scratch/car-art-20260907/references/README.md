# 品质参照与素材

## 选定参照（已观看原图）

- [Albert Limeres — BMW E30 M3 High Poly Model](https://albertlimeres.artstation.com/projects/nYwaE1)：选用 Raw Render，配合作者的 Clay / Wireframe 分解检查引擎盖和翼子板的连续高光、窄而稳定的面板接缝、双圆灯光学层次与轮圈结构。文件 `albert-limeres-e30-raw.jpg`。这是建模与材质参照，不把其黑色配色转移到现有红色 E30。
- [TREY Digital Studio — Porsche 911 GT3 RS](https://www.trey-studio.com/work/porsche-911-gt3-rs/)：摄影 Anke Luckmann，代理 Grabarz und Partner。保存该项目的前轮/灯具近景与车尾视图。重点是轮圈倒角、刹车盘与卡钳层次、灯罩内部可读性、接缝、玻璃及车漆区分。照片带水滴、后期和动态背景，只借鉴结构与表面层次；本轮不添加雨水或复制其涂装。页面明确署名摄影，不把它称为纯 CG。

参照图为原作者版权作品，仅在本地评议中标明出处并排展示。没有用作汽车贴图或宣称为本轮成果。

## 已取得并校验的可用素材

[Poly Haven / Sergej Majboroda — Studio Small 09](https://polyhaven.com/a/studio_small_09)，CC0，2K HDR。用于统一摄影棚反射与暗面填充。已下载实际 HDR 文件，MD5 与官方 API 一致；相较 8K/16K 版本节省内存，当前对比图尺寸下足够检查表面。

元数据通过 Poly Haven 公共 API 取得。Powered by Poly Haven。完整来源及校验值见 `SOURCES.json`。

## 值得手动取得的候选（非交付依赖）

[BlenderKit — Carbon，antoine f](https://www.blenderkit.com/asset-gallery-detail/2adeea73-69f6-4f6d-8a11-56584b2d75db/)：页面标为 Free，2K 无缝黑色碳纤维，约 2.3 MiB。适合 AMG 的碳纤维气动件和 M5 的外部碳件，优点是明确为表面素材、体积小，不要求整车替换。需要通过 BlenderKit/Blendkit 的账号和插件取得实际材质包；本轮不代用户创建账号或扩展连接。

**质量：待验证。** 尚未拿到材质节点与贴图，不能确认纹理尺度、法线强度、方向连续性或实时导出是否正确。现有贴图继续保留，缺少纹理的表面使用本轮可编辑程序材质；候选不作为已完成质量依据。推荐等级：可选补充，不建议为它暂停当前制作。
