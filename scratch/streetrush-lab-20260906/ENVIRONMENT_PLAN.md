# 维修区环境方案：用少量可复用模块建立地点感

这是第一类“先形成完整方案”的本批范围：只确定维修区及相邻直道的空间与制作方案。全赛道的弯道节奏与物理截面不由这个独立样片自动决定。

## 设计选择

保留现有真实车辆和干燥午后场景。建筑选择低层、开放式维修棚，靠柱跨、檐口、室内进深和编号形成尺度。用一个抬高的控制室作地标。道路对面留草地和小型休息棚，避免两堵连续高墙夹住道路。

## 模块与拼装

| ID | 模块 | 样片尺寸/数量 | 组合与职责 |
|---|---|---|---|
| G01 | 开放维修跨 | 每跨沿线5.5m，进深约8.5m，柱高约3.5m；五跨 | 前方开放，后墙统一；两端可局部落下卷帘，保持明暗变化 |
| G02 | 檐口与屋顶 | 总长30m，约0.7m前挑檐 | 连续轮廓，细金属肋与结构梁分开；后续可减少远处几何肋 |
| G03 | 端墙 | 两面 | 可让同一套维修跨独立拼成2、3、5跨短组，不需要总是同长度 |
| G04 | 工作台/工具柜 | 每跨一组 | 给人尺度与使用痕迹；避免用小物件数量充当细节质量 |
| C01 | 控制室 | 低层底座+上层观察窗，总高约5.8m | 放在维修区一端；地标应从回归路线看到，实际生产落位待弧长映射 |
| S01 | 遮阳休息棚 | 约5×6m | 道路另一侧形成不同尺度，不能放在行驶净空内 |
| R01 | 路灯/护栏/牌 | 独立重复模块 | 沿道路分段放置；入口使用间距，不能整场同节奏复制 |

## 独立样片布局

坐标仅用于实验：Y向上，Z沿直道，X横向。

```text
X负侧：远景树群 — 草地 — 休息棚/路灯 — 路肩
                    主路 X≈[-6.5,+6.5]
X正侧：入口锥筒 — 维修区硬地 — 开放车库 — 后方护栏/树群
                    G01 车库前缘X≈9.15，后缘X≈17.8
                    五跨Z≈[-13.75,+13.75]
                    C01 控制室Z≈21.5
```

实验主路宽13m是独立样片选择；生产当前为14m，接入时应服从正式道路截面，不迁移这个数值。样片没有任何新碰撞或摩擦设置。

## 资源与制作取舍

- 沥青与草地复用已有下载原料的底色、法线和ORM中的粗糙度；不重新下载另一套再强行替换。
- 建筑主体使用少量程序化结构模块，因为当前需要的是尺度/拼装验证。若改为精细建筑，优先保留该拼装关系再替换单模块资产。
- 工具柜、柱梁、卷帘、屋面肋和设施是当前几何原型；后续可合批或使用trim纹理。不是最终性能优化版本。
- 树冠和草簇使用确定性的程序化分布。硬地区域排除草；未来自然植被资产替换应继续使用同一布局种子和排除区。
- 已有 MX-5 直接只读加载，使用精确顶点包围盒与轮胎最低点作样片落地校准；不回写生产车模。

## 光照与可控参数

一个方向光产生投影，半球光补天空/地面色，程序天空提供可见天空。当前车漆仍使用静态 RoomEnvironment 预滤波反射辅助，尚未完成户外环境反射与天空同源；这个限制明确保留。

太阳高度、曝光、投影、材质、草簇与设施细节都可切换。材质缩放、法线强度、树群种子与模块尺寸在源代码有明确数值。首版不加入 SSR、动态天气或复杂后处理。

## 判断是否值得进入生产

1. 停车与行驶构图都能读出道路、维修棚和车的尺度，不仅一张展示图好看。
2. 光照开关能解释投影收益，材质开关能解释表面收益；没有浮空车、硬地长草和严重遮挡。
3. 三套UI放在同一场景中比较，而不是用不同精修背景帮助某一套胜出。
4. 接入生产前，以正式中心线/截面重新放置模块，核对碰撞、相机可见性、资源释放和阴影成本。

本方案没有决定全赛道的具体建筑落位；这需要正式路线弧长与驾驶视距采集。它也没有把程序化原型质量当作最终资产质量。
