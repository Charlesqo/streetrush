生成时间：2026-09-05 08:49（本地）
生成者：GLM（ZCode 会话）

## 一、打开方法

1. 打开 `index.html`（与本 README 同目录）。任选其一：
   - 访达双击 `index.html`（默认浏览器打开）；
   - 或终端执行：`open "/Volumes/Storage/streetrush/scratch/glm-audio-20260905-084910/index.html"`
   - 或直接拖入 Chrome / Edge 窗口。
2. **推荐 Chrome / Edge**。Safari 打开 file:// 页面时对媒体加载的策略更严格，若整页所有音层都显示“无法试听”，请换 Chrome/Edge（这是浏览器限制，不是素材损坏）。
3. 页面通过相对路径 `../../public/audio-banks/<车型>/<文件>.wav` 直接读取素材，**没有复制、移动或修改任何音频文件**。因此本目录位置不可挪动，否则音频路径会失效（页面自检区会显示解析出的页面地址，可据此判断）。
4. 点击任意一行的「播放」开始试听；再点一次或点另一行即切换；「全部停止」一键停。同时只播放一层，页面不会自动播放。默认开启循环（素材本身就是 2.5 s 循环审听段，循环是为了听出接缝淡变质量），可用复选框关闭。

## 二、页面内容

- 按车型（mx5 / m3e30 / gt3rs / lp700 / amggt3 / m5g90）分卡，每车列出 bank.json 里**实际引用且在盘**的 6 个音层：转速、给油(on)/收油(off)、load 值、文件名、大小、WAV 头校验、sha256 前 16 位。
- 每车标出：bank id / version、引擎说明、导出器、来源脚本、来源链接、循环处理方式、登记状态。
- **兼容替代音源标识**：六个 bank.json 全部声明 `exactCurrentAsset=false`、`exactEngineSource=false`，页面在每车标题处挂红色徽章「兼容替代音源 · exactCurrentAsset=false」。
- **未确认信息**：每卡一节，逐条摘译自该 bank.json 的 `source.claim` / `registration` / `officialReference` 原文（英文原文在该卡「声明原文」折叠区）。
- **缺失文件标记**：bank.json 引用但磁盘缺失的文件会显示「缺失文件，无法试听」并禁用播放；本次审计 **无缺失**。
- 页面顶部有自检区：统计「可试听 / 无法加载」层数，并列出所有无法加载的具体文件。

## 三、验证记录

### 3.1 磁盘与格式审计（已完成，2026-09-05）

- 六个 `bank.json` 均可解析（schemaVersion 2），共引用 36 层。
- **36/36 全部在盘**：无缺失文件，也无盘上未被引用的多余文件。
- 所有 wav 统一为：RIFF/WAVE PCM16，44100 Hz，单声道，16 bit，2.5 s，220,544 B/文件；36 个 sha256 互不相同（无重复文件）。
- 各车转速点：mx5 1800/4200/6800；m3e30 1800/4200/6800；gt3rs 1800/4500/9000；lp700 1800/4500/8500；amggt3 1800/4500/7600；m5g90 1800/4500/7200（每点各一对 on/off）。
- 明细（含完整 sha256）见 `audit-inventory.json` 与 `audit-summary.md`。

### 3.2 浏览器实测（已完成，2026-09-05）

实测方式：因内置浏览器不能直接打开 file://，起了一个**只绑定 127.0.0.1 的临时静态服务器**（验证完已关闭，不算联网），用 Chrome 内核浏览器加载
`http://127.0.0.1:8741/scratch/glm-audio-20260905-084910/index.html` 进行验证。相对路径与 file:// 打开完全一致。

实测结果：

- **渲染**：6 张车型卡全部正常渲染；标题、素材性质提示、自检区、控制条（音量/循环/全部停止）、来源说明表、英文声明折叠区、未确认信息列表、音层表格均正确显示（附截图确认）。
- **音频路径探测**：36/36 层全部显示「✅ 可试听（元数据已载入，2.50 s）」，0 层无法加载。该探测只读取元数据，不发声、不自动播放。
- **播放**：点击 mx5 `1800-off.wav` 的「播放」→ 行高亮、按钮变「停止」、状态栏显示「正在播放：mx5 / 1800-off.wav（1800 rpm 收油）」、行内出现进度（如 `0.4 / 2.5 s`）。
- **同时只播放一层**：再点 mx5 `1800-on.wav` → 第一层自动停（按钮恢复「播放」、取消高亮），只有第二层在播。
- **全部停止**：点击后无任何行在播，状态栏恢复「未在播放」。
- **缺失/失败路径**：本批素材无缺失，因此「缺失文件」与「无法加载」两种提示在真实数据下未触发（逻辑按状态渲染，属未触发项而非失败）。

实测后的小改动与覆盖说明：

- 实测中发现「停止后行内进度文本不 清空」的小瑕疵，已修复（停止时清空 `.prog` 文本）。修复后重载页面确认 36/36 探测仍全部通过、脚本完整执行；但受自动化点击通路中断影响，未能在浏览器里重放最后一次完整播放/停止操作。该修复只增加“清空文本”一行逻辑，所在函数（停止/清 UI）此前的行为已验证。
- file:// 双击打开的实测未做（由你按第一节操作即可确认）。媒体元素在 Chrome/Edge 下从 file:// 页面加载 file:// 音频不受 CORS 限制，预期行为与实测一致；若你的浏览器整页显示「无法试听」，换 Chrome/Edge，或用下方命令起临时回环服务器后访问：
  `cd /Volumes/Storage/streetrush && python3 -m http.server 8741 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:8741/scratch/glm-audio-20260905-084910/index.html`。
