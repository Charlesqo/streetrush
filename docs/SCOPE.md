# Street Rush 1.0 范围

## 一句话目标

做成一个免费、打开即玩的单赛道计时挑战：一辆重点打磨的主车，加五辆差异清楚的可选车辆，让玩家愿意反复刷新个人最佳。

## 1.0 必须成立

- 一条经过完整打磨的赛道，起终点、刹车点、弯道方向和越界边界都能看懂。
- 三圈流程之外，至少记录逐圈时间、最快圈、个人最佳、与最佳成绩差值，并保存在本机。
- 快速重开真实可用；越界、抄近道和重置会使当前圈无效。
- 至少有一组清楚的目标时间或奖牌，让第一次进入的玩家知道要追什么。
- 主车的加速、极速、制动和定圆表现有可重复测试；生产代码与校准脚本不再维护两套互相偏离的公式。
- 六辆车可以继续保留，但质量标准以主车为先；其他车只承诺可辨认的 simcade 差异，不承诺工程级车辆复现。
- 键盘、常见手柄和手机横屏都能完成一次比赛；低性能设备有明确的降级策略。
- 构建、秘密扫描、素材清单和发布尺寸检查可一条命令重跑。

## 现在明确不做

- AI 对手、生涯、开放世界、多人联机、天气、损伤和第二条赛道。
- “严肃模拟器”“真实还原某量产车”这类需要实车数据与专业验证的承诺。
- 在授权未清理前收费、接广告、接品牌赞助或继续扩大未明来源素材。

这些不是永远取消。1.0 上线后先看玩家是否会完成比赛、是否会重跑、是否会追个人最佳，再决定投入第二赛道、AI 或更深物理。

## 完成定义

只有同时满足以下条件才叫 1.0：核心计时循环完整；无 P0/P1 已知缺陷；目标设备完成实际试玩矩阵；`pnpm verify` 通过；公开发布授权门禁通过；发布版本有 Git 标签、变更摘要和可回滚的上一个构建。
