## 保留的方案

天空以清爽、有云层的晴天下午为目标。同机位比较原天空、程序晴天和 HDRI 后，正常入口保留 HDRI；加载失败时回退程序晴天。太阳方向按 HDRI 最亮像素对齐，天空、太阳阴影与场地环境反射使用同一方向。环境捕获时压低太阳圆盘的极亮峰值，减少不受局部遮挡的环境高光与直接太阳光重复叠加。全局曝光仍为 0.9，没有用提高整场曝光掩盖暗部问题。

新增 Poly Haven Kloofendal 48d Partly Cloudy (Pure Sky) 2K HDR 原文件，5,451,493 bytes。作者 Greg Zaal / Jarod Guest，CC0；来源与校验和保存在素材清单及 `licenses/evidence/polyhaven-kloofendal-sky.txt`。下载体积不代表 GPU 显存。来源：[素材页](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky)、[授权](https://polyhaven.com/license)。

轮胎烟针对刹车／滑移触发的现有效果，改为带不规则软边的实例面片，按时间发射、沿车轮移动轨迹插值、增长并逐渐降低透明度。消散不再通过把 RGB 变黑实现。烟雾读取统一太阳阴影图和主场景深度，使用轻量受光近似与软交界，在 GTAO 后、统一色调映射前合成；烟雾不进入不透明场景深度或 AO 计算。它不是完整体积散射，也没有烟雾自遮阴。

胎痕使用连续、带软边和细条纹的乘法混合带状几何，保留下方沥青纹理、照明与投影。缓存赛道浅表面高度以跨过略高的白线和起点棋盘格；不在每帧对整场景做射线查询。保留现有车轮接地、速度与滑移触发条件，未修改轮胎物理状态。

运行时降画质优先降低 GTAO 分辨率，再降低主画面分辨率；恢复增加稳定窗口，减少来回切换。开发静态预览限制 5 FPS，并调用已有暂停机制停止车辆模拟；正常预览、行驶与性能窗口临时恢复，结束后自动暂停。正常游戏入口不受开发预览帧率上限影响。

## 实机证据与清晰度

交互页含三种天空、旧／新轮胎烟、旧／新胎痕、两档车尾原始绘制分辨率及独立烟雾遮光样例。天空截图采用同机位、58° FOV、1.35 渲染比例。效果样例使用固定种子与固定时间。旧效果存在陈旧包围体裁剪，诊断对照只关闭此裁剪使原有粒子材质可见，因此不称为未经修改的旧版生产回放。

高清车尾帧实际为 2560×1440，绕过动态分辨率和总像素预算；低档实际为 921×518，两者按同一显示尺寸比较。PORSCHE 字标在高清近景中可以读清，低分辨率会丢掉很薄的笔画。原 GLB 中对应车尾字标的候选几何使用 chrome 材质、没有 baseColor 贴图，不能把它全部归因于低清颜色贴图。原模型检查数据保存在 `porsche-rear-badge-candidates.json`。没有改写字体或替换用户的车材质。

移动录像为游戏 Canvas 原始 WebM，1280×720、30 FPS 录制、约 8 秒，游戏正常刷新。检查了 2／4／6 秒关键帧及末段播放：烟雾沿轮迹展开，胎痕持续接续，没有旧版方块烟的硬边。开发工具让真实行驶车辆持续触发视觉效果，以便观察尾迹；只改复制的视觉遥测，不能用该录像证明普通刹车必然达到冒烟阈值。录制与性能测量分开进行。

## 性能

Apple M4，Codex 应用内浏览器，ANGLE / Metal，固定 1280×720。HDRI、同机位、同赛道，车辆视觉隐藏；近镜头烟团固定，无胎痕。真实比赛状态与正常模拟，预热 3 秒后以正常刷新率采样 12 秒。每组 720 个整帧和有效 GPU 样本，GPU 计时拒绝 disjoint 数据。采样期间不做其他工具操作；本机其他应用负载未完全控制。

|---|---:|---:|
| GPU 平均 ms | 4.460 | 5.244 |

| 渲染提交 CPU 平均 ms | 0.289 | 0.339 |

这组近镜头烟样例增加约 **0.784 ms GPU** 和 **0.050 ms 渲染提交 CPU**，多一次绘制。粒子池最多 180 个；同时按投影面积限制重叠，实测近镜头样例提交 45 张面片、估算累计覆盖 3.561 屏。面积预算允许最后一张面片越过边界；该数字是累计重复覆盖估算，不是不透明屏幕占比。

这只分离了该烟团的渲染增量，没有测量完整天空更新的增量、移动中的粒子更新 CPU 成本或整套新版相对旧版的成本。不能外推所有车辆、分辨率和长期帧率。完整旧／新版六车记录仍以[上一轮报告](LIGHTING_AND_MATERIALS_REVIEW.md)为准；本轮没有重复已确认的六车检查。
