## 已退出当前入口的历史开发小样

`src/dev-diffuse-probe-review.js` 使用 Three.js 的 `LightProbeGenerator`，在护栏附近两个高度各捕获一次 32×32 线性 HDR 立方体，再生成九项球谐系数。捕获包含真实天空、已受光地面与场景阴影，隐藏车辆、排除场景雾、压低天空太阳圆盘峰值。采样结束恢复场景与渲染目标。

在有限区域内，以按高度混合的采样替换原有漫反射环境光和半球补光；原镜面环境反射保留。没有在现有环境漫反射上直接叠加一份亮度。对实例几何使用实际世界位置，注入时串联已有 `onBeforeCompile`。每帧不捕获，不新增绘制 pass。当时从明确的 DEV 检查模式动态加载；现在入口已撤除，源码只保留作历史记录。

验证了三组，组内只切换间接光：

1. 原护栏材质：metalness 0.72、roughness 0.38，实际变化偏弱。
2. 临时涂层材质：metalness 0.02、roughness 0.72，正常地面，无色板。
3. 同样的临时涂层材质，加非自发光的橙色地面测试板。板与护栏颜色在开关前后均相同，开启局部间接光后护栏暗面出现暖色反光。

颜色验证说明链路确实传递了周围表面的颜色，但不证明这个低密度采样已经具有成熟游戏的完整空间精度。该小样只使用两个高度样本和一个局部权重范围，会扩散颜色、缺少精细空间遮挡；尚未处理全赛道采样、跨区域过渡、场景改动后的重建。**没有将其或临时涂层、色板接入正常游戏，也不把它称为完整或多次反弹 GI。**

## 小样性能与验证

Apple M4 / ANGLE Metal，1280×720，护栏机位、正常地面、临时涂层、无色板；真实比赛模拟，静态阴影缓存。每组预热 3 秒后采样 12 秒，正常刷新率；无烟。开关组均已注入同一开发着色器，关闭组跳过球谐照明计算，不能当作未注入着色器的生产基线。

| 指标 | 关闭 | 开启 |
|---|---:|---:|
| GPU 平均 ms | 2.920 | 2.987 |
| GPU P95 ms | 3.812 | 3.851 |
| 渲染提交 CPU 平均 ms | 0.543 | 0.521 |
| 绘制次数 | 66 | 66 |

此局部样例 GPU 增量约 0.067 ms；未计一次性采样耗时，不外推到全场景、所有机位或手机。
