# 六车发动机候选音频试听整理

更新日期：2026-08-21。本文只评价当前生产目录 `public/audio-banks/` 中的六套候选，不把文件能解码、能循环或能被运行时加载等同于听感合格。

## 先说结论

- 36 个 WAV 不是 36 个独立候选，而是每车一个 Engine Simulator 模型的 `3 个转速 × on/off load` 六层输出。
- `research-salvage/audio/candidates/` 与 `public/audio-banks/` 的 WAV 是同一批内容，不需要重复试听。
- 六套 `stems.json` 都只有 `exhaust_mix`；没有独立进气、机械、涡轮、传动、回火或环境录音。
- 全部文件都是 2.5 秒、44.1 kHz、单声道 PCM16 循环。循环技术门槛通过不代表它们像目标车辆。
- 机器筛查显示全部候选都高度窄带、周期稳定，2–8 kHz 高频能量平均占比均低于 0.4%，因此“电钻/蜂鸣器”风险不是个别文件问题，而是整批生成方法的共同限制。

## 机器筛查

| 车辆 | 平均周期性 | on/off 频谱相似度 | 平均负载响度差 | 判断 |
| --- | ---: | ---: | ---: | --- |
| AMG GT3 | 0.527 | 99.98% | 0.06 dB | 直接淘汰建议：on/off 实际几乎同一声音，六层中的一半没有信息量 |
| M5 G90 | 0.812 | 84.97% | 5.16 dB | 直接淘汰建议：4500/7200 rpm 的 on-load 分别比 off-load 小约 8/5 dB，且来源并非正确的涡轮/混动 S68 声音 |
| MX-5 | 0.951 | 75.49% | 0.69 dB | 高风险：六车中周期性最高，最容易形成稳定“电钻”音色 |
| M3 E30 | 0.812 | 91.70% | 1.49 dB | 高风险：中高转高度周期化，低转层又异常安静 |
| LP700 | 0.639 | 93.57% | 0.88 dB | 只值得一次人工确认：可能保留 V12 次序感，但动态仍非常平直 |
| GT3 RS | 0.519 | 98.90% | 0.52 dB | 六套中最值得先听，但 on/off 仍近乎重复；若高转没有明显 flat-six 质感就应整套淘汰 |

周期性越接近 1，越像稳定重复的机器音；on/off 频谱相似度越接近 100%，负载分层提供的信息越少。上述指标只用于缩小试听范围，不代替人耳结论。

## 最小试听顺序

按下面顺序听即可，不需要把 36 个文件逐个打开。

1. `public/audio-banks/gt3rs/4500-on.wav` 与 `9000-on.wav`
   - 只判断中高转是否有自然的 flat-six 排气质感、转速提升是否从“脉冲”变成有层次的尖啸。
   - 如果仍是单一电钻音，当前六套里没有更值得保留的完整方案。
2. `public/audio-banks/lp700/4500-on.wav` 与 `8500-on.wav`
   - 判断能否听出 V12 的密集点火与高转延展，而不是更高音调的同一蜂鸣声。
3. `public/audio-banks/amggt3/4500-off.wav` 与 `4500-on.wav`
   - 这是反例 A/B；如果听不出负载差异，与 99.99% 的频谱相似度一致，可直接整套停用。
4. `public/audio-banks/m5g90/4500-off.wav` 与 `4500-on.wav`
   - 这是响度反向反例；后半段 on-load 明显更小并不符合当前混音用途，可直接整套停用。
5. 只有在前两套勉强可用时，再各抽听 `m3e30/6800-on.wav` 和 `mx5/6800-on.wav`。

## 建议处理

- AMG GT3、M5 G90：不再投入时间修补当前 WAV；保留 manifest/来源记录作失败证据，生产听感应回到程序化 fallback 或换新来源。
- MX-5、M3 E30：最多各听一个高转层；若仍有明显电钻感，整套停用，不继续调整 gain 或 crossfade 来掩盖源音色问题。
- GT3 RS、LP700：仅作为唯二人工复核候选。通过条件不是“能听”，而是中高转车型差异明显、负载变化可信、连续驾驶不疲劳。
- 下一批素材必须优先解决源内容，而不是继续生成同格式六层：至少需要真实或可信合成的排气与进气差异、负载变化、宽带机械纹理，以及可验证的授权。
