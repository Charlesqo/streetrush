清理保留原有 53 次提交。清理前后逐提交对照：文件树仅减少上述路径，作者、日期、提交说明和提交间关系保留；受影响提交的 SHA 改变。本轮小资料及说明另作新提交。

原历史另有本地 bundle 备份。它仍包含被排除的脚本，仅供本地恢复，不能上传，也不要将旧历史合并回来。原工作目录中的这些脚本保留为本地忽略文件。本地 Codex 检查点未清除；它们不随普通 `main` 推送上传。禁止用 `git push --mirror` 上传全部本地引用。

这次改写的是本仓库分支历史，不能据此保证其他克隆、分叉或平台缓存中的旧对象消失。后续在其他电脑使用旧克隆时，应先保存未提交工作，再使用整理后的历史。
